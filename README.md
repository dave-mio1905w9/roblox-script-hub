# roblox-script-hub

I got tired of Roblox Studio's search and the web Creator Dashboard's latency. This fetches all scripts from a place I own, caches them locally, and lets me grep through everything from a terminal.

## install

pip install -r requirements.txt

## usage

python hub.py --token $(cat .rbx-token) --place 123456789
